# Contributing to Mac Companion

Mac Companion is not yet ready to accept external contributions. The source is
visible while Jenny Media LLC completes the repository license, contribution
terms, trademark policy, and private vulnerability-reporting route. Opening the
repository does not grant a license beyond rights that applicable law provides.

Please do not submit pull requests until this notice is replaced by an approved
contribution policy. A later policy is expected to use a Developer Certificate
of Origin unless Jenny Media LLC deliberately adopts different terms.

Do not disclose a suspected security vulnerability in a public issue or pull
request. Private vulnerability reporting is not yet enabled, so this repository
is not open for external security testing or vulnerability intake. A reviewed
`SECURITY.md` with a private destination is required before that changes.

Published source does not provide Jenny Media signing identities, official
bundle identifiers, update-feed authority, trademarks, managed Apple
entitlements, or permission to impersonate an official release. Forks must use
their own product identity, signing team, update infrastructure, and Apple
capability requests.
