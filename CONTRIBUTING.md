# Contributing to Mac Companion

Mac Companion is not yet ready to accept external contributions. The source is
available under Apache-2.0 while Jenny Media LLC completes written legal review
of the license, `NOTICE`, contribution terms, trademark policy, code of conduct,
and private vulnerability-reporting route.

Please do not submit pull requests until this notice is replaced by an approved
contribution policy. The intended policy uses Developer Certificate of Origin
1.1 sign-off unless Jenny Media LLC deliberately adopts different terms. Do not
add a `Signed-off-by` line yet: the repository is not accepting contributions.

Do not disclose a suspected security vulnerability in a public issue or pull
request. Follow `SECURITY.md`, which truthfully records that private reporting
is not operational yet. This repository is not open for external security
testing or vulnerability intake until that route is enabled and verified.

Published source does not provide Jenny Media signing identities, official
bundle identifiers, update-feed authority, trademarks, managed Apple
entitlements, or permission to impersonate an official release. Forks must use
their own product identity, signing team, update infrastructure, and Apple
capability requests.

Participation in project spaces is also governed by `CODE_OF_CONDUCT.md`.
